# Исходные ролики

Восемь папок, по одной на шаблон. Имя папки = `template_id` в базе.
Видео в git не коммитятся (см. `.gitignore`), уезжают в S3 командой `seedclips`.

```
clips/<id>/
  video.mp4      ← исходник, 4–30 сек. Не переименовывать
  request.json   ← рабочий формат Higgsfield: prompt + image_1..N. НЕ ТРОГАТЬ
  meta.json      ← наше: название, описания, подписи ролей, цены
```

## request.json — источник правды

Из него берутся:
- `prompt` → промпт для Genjutsu Lite, дословно
- число ключей `image_1 … image_N` → сколько фото просим у клиента (1–8)

Файл правится только если меняется сам промпт. Длина `slot_labels_ru` и `slot_labels_kz`
обязана совпадать с числом `image_N` — иначе `seedclips` откажется заводить шаблон.

## meta.json

| поле | что это |
|---|---|
| `name` | название трека или мема, как есть. Не переводим: `Hotel Lobby` остаётся `Hotel Lobby` |
| `desc_ru`, `desc_kz` | что получит клиент, одной строкой |
| `slot_labels_ru`, `slot_labels_kz` | подписи слотов загрузки, по одной на каждое фото |
| `poster_at` | секунда, с которой брать постер. `null` = автоматически на 35% длительности |
| `price_480p`, `price_720p`, `price_1080p` | цена в тенге. `null` = качество не продаём |
| `popular` | плашка «Популярное» |
| `sort` | порядок в каталоге |

**Все три цены `null` → шаблон заводится с `active=false` и в каталоге не появляется.**
Сейчас цены пустые у всех восьми — каталог будет пустым, пока не проставишь.

### poster_at

Первый кадр часто не отражает содержание: у `hotel-lobby` это оранжевый фон,
у `raindance` — девушка у моря, хотя продаются совсем другие сцены. Поэтому по
умолчанию постер берётся с 35% длительности. Если и там промах — впиши секунду
в `poster_at` и прогони `seedclips` заново.

## Слоты — это роли, а не ракурсы

Genjutsu Lite раздаёт персонажей по порядку: `image_1` → первая роль, `image_2` → вторая.
Подписи должны объяснять клиенту, чьё фото он грузит в каждый слот:

- `raindance` — мужчина и женщина, два разных человека
- `delai` — главный герой, снимающий селфи, выходящий между машин
- `hotel-lobby` — двое, но `image_2` и `image_3` это **один и тот же человек с двух ракурсов**
- `drake-party` — главная героиня плюс пятеро в массовке

## Запуск

```
go run ./cmd/seedclips
```

Идемпотентно: подменил видео или правил `meta.json` — прогнал снова.

Без доступа к серверу то же самое делается через `/admin` (пароль из `ADMIN_PASSWORD`).

## Известные проблемы

- `enzo` — обрезок трансляции 776×502 с логотипами телеканала. Самый слабый исходник,
  результат будет мыльным. Стоит найти версию получше.
- Своя цена ставится на каждую пару «ролик × качество»: себестоимость зависит
  от длины. Genjutsu Lite принимает максимум 15 секунд, поэтому длинный `lean`
  генерируется двумя последовательными половинами. Проверь стык перед продажей:
  независимые генерации могут немного различаться лицом, одеждой или светом.
- `3_meters` и `cadafi-football` — промпты написаны синтаксисом веб-редактора
  (`@Image 1`, `@Video 1`). В API ментионы не разрешаются, это просто текст.
  Проверяется первым живым вызовом; если персонаж не подменится — переписать
  в стиль `delai` или `raindance`.
