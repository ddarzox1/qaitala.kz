# Цены Genjutsu Lite с валовой маржой 40%

Расчёт на 25 октября 2026 года по курсу НБК `1 USD = 451.05 ₸`.

## Методика

Маржа считается как доля цены, а не как наценка:

```text
маржа = (цена - себестоимость) / цена
цена при марже 40% = себестоимость / 0.60
```

Использованы полные тарифы Genjutsu Lite без временной скидки:

| Качество | Цена за одну billable-секунду |
|---|---:|
| 480p | $0.05 |
| 720p | $0.10 |
| 1080p | $0.20 |

Higgsfield считает входные **плюс** выходные секунды. Для ролика до 15 секунд
это примерно удвоенная длительность. Длинный ролик делится пополам; длительность
каждой выходной половины округляется вверх отдельно.

Формула billable-секунд:

```text
до 15 секунд:  input + output ≈ 2 × duration
длинный ролик: duration + ceil(duration / 2) + ceil(duration / 2)
```

Итоговая цена округлена вверх до 100 ₸. Поэтому фактическая маржа будет не ниже
40%. Комиссия Kaspi, налоги, R2 и прочая инфраструктура в себестоимость не
включены — это валовая маржа генерации.

## Как применить

Без перезаливки роликов удобнее изменить цифры через `/admin`. Для шаблонов,
которые есть в `clips/`, можно также обновить `price_480p`, `price_720p` и
`price_1080p` в `meta.json`, затем выполнить:

```sh
go run ./cmd/seedclips
```

Перед массовой сменой цен сделать один живой заказ в каждом качестве и сверить
фактическое списание в Higgsfield. Если на аккаунте действует скидка 50%, эти
цены дадут дополнительный запас; таблица от скидки не зависит.
